Security Imports Hosted Privacy

Privacy

Your archive is designed around minimization: encrypted sync by default, plaintext only when you ask a hosted compute endpoint to work on it.

Data promises.

Default opacity

Synced conversations, participants, artifacts, and relation facts are ciphertext to the backend.

Explicit compute

Transcription, OCR, and LLM extraction need clear user action and usage accounting.

Portable exports

The normalized model keeps data ready for future export and self-hosted migrations.

Local index

Search is built from decrypted device state, not server-side plaintext indexing.

This prototype is not a legal privacy policy.
